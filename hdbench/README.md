# HDBENCH

**種別 / Type**: フリーソフト / Freeware

## 概要
パソコンの **CPU・DISK・VIDEO** の性能を測定する総合ベンチマークソフトです。
HDD以外の測定は **Dual CPU** に対応しています。

## 対応OS
- Windows 95 / 98 / NT4.0 / 2000 / XP

## ダウンロード
[Releases](https://github.com/HDBENCH/software/releases) からZIPをダウンロードしてください。

---

## Overview (English)
An all-in-one benchmark that measures your PC's **CPU, disk, and video** performance.
All tests except the HDD test support **dual CPUs**.

**Supported OS:** Windows 95 / 98 / NT4.0 / 2000 / XP
**Download:** Get the ZIP from [Releases](https://github.com/HDBENCH/software/releases).
