# FDBENCH

**種別 / Type**: フリーソフト / Freeware

## 概要
HDD・フラッシュディスク・USBフラッシュドライブの性能を測定するベンチマークソフトです。

計測項目：

| 項目 | 内容 |
|------|------|
| Read / Write | シーケンシャル リード・ライト速度（KByte/sec） |
| RandomRead / RandomWrite | ランダム リード・ライト速度（KByte/sec） |
| Copy | Read / Write / Delete の回数/分 または速度（KByte/秒） |

## 対応OS
- Windows 95 / 98 / NT4.0 / 2000 / XP

## ダウンロード
[Releases](https://github.com/HDBENCH/software/releases) からZIPをダウンロードしてください。

## Overview (English)
A benchmark that measures the performance of HDDs, flash disks, and USB flash drives.

| Test | Measures |
|------|----------|
| Read / Write | Sequential read/write speed (KByte/sec) |
| RandomRead / RandomWrite | Random read/write speed (KByte/sec) |
| Copy | Read / Write / Delete operations per minute, or KByte/sec |

**Supported OS:** Windows 95 / 98 / NT4.0 / 2000 / XP
